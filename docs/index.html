card-dispenser

Tune the wave

Cards stand edge-on around a drum. While it turns, the ones near the front rise and settle back; when it stops, exactly one stands up to face you. How wide that wave reaches and how fast its shoulders fall are yours to set — drag the sliders and watch both drums, which always turn together.
